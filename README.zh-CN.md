# ja-ai-polish

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

根据 brief 直接生成自然日语，或者在不改变事实、语体、术语、责任关系和作者意图的前提下，
去除日语草稿中的模板化 AI 写作痕迹。

`ja-ai-polish` 诊断的是可观察的写作问题，不判断文本是否由 AI 创作，也不以绕过检测器为目标。

## 功能

- **直接生成：** 根据用户提供的事实和限制生成符合场景的日语。
- **去 AI 味改写：** 以达到目标所需的最小修改改善 AI 生成或其他来源的日语草稿。
- **仅检测：** 解释问题模式及证据，不改写正文。
- **作者声音校准：** 可选参考 2～5 段作者日语样本中的重复特征。

## 适用范围

适用于工作邮件、Slack/Teams 消息、社交发帖、状态更新、仓库维护、Qiita/Zenn 技术文章、
教程、博客、note 和社区写作。

## 核心原则

1. 诊断可见问题，而不是猜测作者身份。
2. 先保护事实，再改善文风。
3. 把短语视为信号，而不是禁词。
4. 根据渠道、受众和目的选择场景。
5. 作者样本优先于通用润色规则。
6. 对每份生成稿或改写稿执行强制审计。

## 快速示例

直接生成：

```text
使用 /ja-ai-polish 写一条日语 Slack 进度消息。
事实：API 修复完成；负载测试还没做；佐藤负责，周四前完成。
只返回成稿。
```

去 AI 味改写：

```text
使用 /ja-ai-polish 改善下面的日语草稿，去除模板感。
保留所有数字、产品名和承诺。模式：edit；强度：standard。

[草稿]
```

仅检测：

```text
使用 /ja-ai-polish 检查下面的日语，只标注问题，不要改写。
```

## write / edit / detect 模式

| 模式 | 输入 | 输出 |
|---|---|---|
| `write` | 包含目的、受众、事实和限制的 brief | 日语成稿及简短生成说明 |
| `edit` | 日语草稿 | 最小必要修改后的成稿及修改说明 |
| `detect` | 日语草稿 | 严重度、规则 ID、证据、解释和建议 |
| `auto` | 自然语言请求 | 自动路由到以上模式 |

`edit` 支持 `minimal`、`standard`、`aggressive`。长文本或可能涉及整句删除时使用
`bounded`，把删除候选单独列出，而不是静默删除。

## 模式地图

| 识别信号 | 默认动作 | 例 |
|---|---|---|
| 冗长语法、名词化 | 改成直接动词，保留正式程度 | `確認を行います` → `確認します` |
| 空泛评价词 | 使用输入中已有的结果、指标或影响；没有依据时标注缺口 | `非常に効果的です` → 写明已有实际效果 |
| 模糊判断、责任回避 | 写出已知条件、判断或下一步 | `場合によります` → 写明已知分支 |
| 接续词过度 | 删除不承担逻辑功能的连接词 | 连续 `さらに／一方／つまり` → 自然衔接 |
| 文章导航、过度照顾读者 | 直接进入内容 | `本記事では〜を解説します` → 直接说明主题 |
| 定型结尾 | 落到已有结果、限制、决定或下一步 | `今後の発展が期待されます` → 写明已知计划 |
| 翻译腔、夸张搭配 | 写清具体主体与动作 | `重要な役割を果たす` → 写明实际作用 |
| 句长、句尾过于整齐 | 在不改变含义时重新组织信息 | 连续四句 `〜です` → 自然节奏 |
| 缺少具体性或立场 | 使用输入已有的主体、条件、指标和选择 | `総合的に判断することが重要` → 写明选择 |
| 机械共感 | 根据双方关系直接回应具体问题 | `素晴らしい質問ですね` → 直接回答 |

这些表达不是禁词。只有密度、位置、功能、依据缺失和其他信号共同出现时才考虑改写。
完整边界见[去 AI 味规则](references/de-ai-patterns.md)。

## Scene Pack

| 场景 | 优先目标 |

| 工作邮件 | 目的、请求、负责人、期限和适当礼貌 |
| 工作消息 | 可执行的上下文与简洁协作 |

| 技术文章 | 技术准确性、证据、限制和可执行细节 |
| 公开写作 | 有依据的作者声音和非模板化结构 |

## 忠实性保证

生成或改写前，Skill 会建立包含名称、事实、数字、日期、代码、术语、主体—行为—对象关系、
否定、条件、不确定性和承诺的输入台账。完成后逐项核对。缺失的信息会询问或保留空缺，不会
为了流畅而编造。

## 作者声音校准

提供 2～5 段样本后，Skill 会校准句子节奏、语体、主语省略、直接程度、标点和评价性语言
的频率。只学习重复特征，不复用样本中的事实或标志性句子。

## 已知限制

- 自然度依赖上下文，不能简化为短语黑名单。
- 信息稀疏的 brief 无法产生有依据的具体内容。
- 法务、HR、学术等高风险文本仍需合格人员审核。
- 本 Skill 改善写作质量，但不能证明作者身份。
